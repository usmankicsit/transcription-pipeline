Drop a WAV or MP3. Cue returns the words and the start and end of every phrase, ready for captions, search, or the next system in line.

What the pipeline does

  1. Accept A file upload or a path. The name is not trusted. The bytes are.
  2. Decode ffmpeg turns every container into 16 kHz mono PCM. The model sees one format.
  3. Cut Long audio is split on silence, about every five minutes. A hard cut overlaps by two seconds.
  4. Transcribe Whisper reads one chunk at a time. Times are shifted back onto the original clock.

    The production service is the Python package in the repository: faster-whisper, ffmpeg, checkpoints, and an HTTP API. This page calls that service when it is running. On the public demo it runs Whisper in the browser, because a serverless host cannot hold the model and a long job.
